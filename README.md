# 謎解き補助アプリ（Streamlit版）

画像のイメージをベースにした、推理マトリクスの最小構成です。

## 実装済み

- 「人物」「凶器」「犯行現場」の3種類をプルダウンから選択
- テキスト入力でワードを登録
- Enter / 入力欄の変更、または「書き込み」ボタンで登録
- 登録ワードから以下3種類のマトリクスを自動生成
  - 人物 × 凶器
  - 人物 × 犯行現場
  - 凶器 × 犯行現場
- セルをクリックして状態を循環
  - 1回目：○
  - 2回目：×
  - 3回目：空欄
- リセットボタン
- Streamlitのセッション状態で、ページ操作中のデータを保持

## 起動方法

Python 3.10以上を推奨。

```bash
pip install -r requirements.txt
streamlit run app.py
```

ブラウザで表示されたURLを開いてください。

## 次に追加しやすい機能

### 1. 音声入力
現在はブラウザ標準の音声認識をまだ組み込んでいません。
Web Speech APIを使ったカスタムStreamlitコンポーネントにすると、
「マイク → 音声を文字化 → 入力欄 → 書き込み」まで実装できます。

### 2. 推理ロジック
例えば「人物×凶器」で○を付けたら、同じ人物の他の凶器を自動的に×にする、
などのマーダーミステリー／名探偵ゲーム向けの論理推論も追加できます。

### 3. 保存・復元
JSONなどへ保存すれば、途中の推理状態を後から復元できます。
